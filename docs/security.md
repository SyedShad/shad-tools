# Installation and data security

The November 19, 2026 review covers Shad’s eight feature modules, the shared launcher, installer scripts and the embedded capture engine. It combines source inspection, dependency checks, regression tests and inspection of built macOS products. It does not certify the code or third-party services.

## Installing a preview

Preview installers are unsigned. The Shad apps use ad hoc signatures with the hardened runtime. macOS can block a downloaded preview, and a matching SHA-256 checksum establishes a match to the published bytes rather than the publisher's identity. Download the installer and matching checksum file from the same Shad Tools release. Keep Gatekeeper enabled. Distributors with Developer ID Application and Installer certificates can sign and notarize a build and run `REQUIRE_DISTRIBUTION_SIGNING=1 ./scripts/verify-packages.sh` to require those credentials and a stapled ticket. [GitHub releases](https://github.com/SyedShad/shad-tools/releases) · [Apple’s guide to downloaded apps](https://support.apple.com/en-us/102445) · [Apple’s notarization guide](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)

Each installer contains one app, with no install scripts, services installed as root or package dependencies. Launching a tool runs it as the logged-in user. The verifier checks the archive contents, package and bundle IDs, both architectures, linked modules, signature, permissions, helper location and checksums. The suite and Capture include an additional sandboxed app for the MacShot editor and recorder. [Package verifier](../scripts/verify-packages.sh)

## Findings addressed

| Area | Change and evidence |
| --- | --- |
| Embedded updater | The 0.5.0 capture packages included MacShot’s Sparkle 2.9.0. Two high-severity advisories cover that version. Its launch arguments disabled automatic checks while leaving manual updates available. The replacement compiles the full MacShot capture source without Sparkle. The package checks reject nested updater executables and updater permissions. Install a newer Shad package to update this engine. [Upstream advisory on update validation](https://github.com/sparkle-project/Sparkle/security/advisories/GHSA-3x7w-j75x-ppq5) · [Upstream advisory on updater cache handling](https://github.com/sparkle-project/Sparkle/security/advisories/GHSA-4v99-qgq9-6pxp) |
| Capture routing | Shad verifies the enclosing app and its sealed capture helper, then uses the helper’s designated signature requirement to verify any running Shad engine before delivering URLs or user-selected documents. The embedded build has its own identity and settings. [Capture routing](../Sources/Features/Capture/CaptureTool.swift) |
| Existing clipboard databases | Opening history now checks the owner and file type, refuses links at the history directory or database file and repairs overly broad POSIX permissions on an existing history. The private directory is mode 0700 and the SQLite database is 0600. The migration regression uses a temporary database. [Clipboard storage](../Sources/Features/Clipboard/ClipboardStore.swift) |
| Clipboard working copies | Opening or previewing an item used to leave an extra file behind after deletion. Edits, deletion, clearing, retention and eviction now remove the associated files under the same database lock used to create them. The upgrade recovers markup for surviving entries and removes orphan previews. Files explicitly saved by the user and original files referenced from Finder remain user-managed. [Working-copy lifecycle](../Sources/Features/Clipboard/ClipboardStore.swift) |
| Rich clipboard parsing | The recorder checks byte limits before parsing HTML, RTF, RTFD and archived colors. HTML previews use local XML parsing with external entity loading disabled. A regression covers an oversized HTML-only item. [Pasteboard reader](../Sources/Features/Clipboard/ClipboardPasteboard.swift) |

## Permissions and user data

| Tool | What it can access |
| --- | --- |
| Search | Applications and indexed file metadata visible to the current user. Opening a result or showing a preview uses macOS services. |
| Audio | Core Audio’s available devices and default routing. Persisted rankings identify hardware by its Core Audio UID. Changing the default microphone does not start recording. |
| Eject | Shad runs the fixed system `/usr/sbin/diskutil` binary using separate arguments and validates a fresh physical-device attachment before ejecting. Internal, startup and unsuitable storage are filtered. Busy drives return an error. |
| Color | The macOS sampler returns the color the user selects. The Color tool stores a local recent-color list. |
| Windows and Mouse | Window arrangement and posting selected key shortcuts need Accessibility. The mouse event tap handles assigned pointer events. Shortcut recording uses the settings interface. macOS can revoke these permissions in Privacy & Security. |
| Clipboard | Clipboard history, OCR, snippets and copied file references live in the current user's Application Support directory. SQLite uses parameter binding and secure deletion. Labels from the pasteboard identify known password managers and transient or concealed copies. Unmarked sensitive content from other apps can still enter history. Clipboard History can pause collection. Direct paste uses Accessibility. |
| Screen and presenter recording | macOS controls screen, camera, microphone and optional speech transcription access for the app performing each operation. The presenter writes a local movie. The sandboxed engine permits user-selected files, camera, microphone, bookmarks and outbound connections for optional providers. Its settings expose the URL scheme and sharing controls. |

Clipboard AI processes selected items with Apple’s on-device model on supported systems. Opening a third-party chat uses a fixed provider address. The user chooses what to paste and send. MacShot's optional upload and translation services can receive selected data. Google Drive credentials in the engine use a user-only token file. User-provided S3 and imgbb settings use the sandbox’s preferences. Capture settings exports filter credential and S3 keys. Account access, device backups and the security of the selected provider remain relevant. Clipboard files and app data are not independently encrypted by Shad. [Clipboard actions](clipboard.md) · [MacShot privacy policy](https://github.com/sw33tLie/macshot/blob/v4.4.0/PRIVACY.md)

## Dependency and release checks

Shad’s feature modules use Apple frameworks and the system SQLite library. The capture build pins the upstream source and artwork plus Swift-WebP, libwebp-Xcode and libwebp to exact revisions and SHA-256 digests. Each capture package includes the patched source, dependencies, licenses and build recipe. The upstream signature is checked before its artwork and localization files are staged. An exact-commit query of OSV returned no entries for the three WebP revisions on the review date. The libwebp source identifies itself as 1.5.0. An NVD exact-CPE query for applicable CVEs also returned zero for libwebp 1.5.0. The two high-severity Sparkle advisories cover versions through 2.9.5 and mark 2.9.6 as patched. The review checked the previous installer’s framework version directly. The new engine contains no Sparkle executable or services. An empty advisory result cannot rule out undisclosed defects. [Capture build inputs](../scripts/prepare-capture-engine.sh) · [Source revisions and licenses](../ThirdParty/MacShot/NOTICE.md) · [OSV database](https://osv.dev/) · [NVD vulnerable-product query for libwebp 1.5.0](https://services.nvd.nist.gov/rest/json/cves/2.0?cpeName=cpe%3A2.3%3Aa%3Awebmproject%3Alibwebp%3A1.5.0%3A%2A%3A%2A%3A%2A%3A%2A%3A%2A%3A%2A%3A%2A&isVulnerable=)

The macOS pull-request workflow uses read-only repository access, an immutable checkout action revision and no signing credentials. It runs the tests and independently builds and verifies the packages. The source review also checked tracked Shad history for common credential formats. Physical-device coverage and feature gaps are recorded separately. [Continuous integration](../.github/workflows/check.yml) · [Feature coverage](feature-coverage.md)
